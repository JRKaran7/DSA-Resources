Convolutional Neural Network (CNN) Pipeline

CNNs automatically learn hierarchical features directly from raw image data

  1. 1. Conv2d + ReLU Extracts local edges early on, and complex object parts in deeper layers.
  2. 2. MaxPool2d Downsamples spatial dimensions (e.g., 32×32 → 16×16) for translation invariance.
  3. 3. Flatten + Linear Maps extracted feature maps to final class probabilities via Softmax.
